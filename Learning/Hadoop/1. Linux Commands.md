# Linux Commands on Dataproc Cluster

This document covers basic Linux file system and navigation commands executed through the SSH terminal of the Google Cloud Dataproc cluster.

The commands were executed on the master VM of the Dataproc cluster. Files created using standard Linux commands are initially stored on the local file system of the VM and are not automatically distributed through Hadoop.
