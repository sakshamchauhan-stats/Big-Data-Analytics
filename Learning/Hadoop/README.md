## Hadoop

This folder contains hands-on learning and implementation of Hadoop and distributed data processing using Google Cloud Platform (GCP).

The learning environment was created using Google Cloud Dataproc, with Google Cloud Storage (GCS) used for cloud-based data storage.

### Overview

The implementation focuses on understanding how Hadoop can be deployed and accessed through a managed cloud environment using Dataproc.

It covers cluster creation, cloud storage configuration, and working with Hadoop and Linux commands through the Dataproc cluster.

### Content

#### Hadoop & Linux Commands
- Accessed the Dataproc cluster through SSH
- Executed Linux commands
- Executed Hadoop commands
- Explored basic interaction with the Hadoop environment
- MapReduce
- Hive

### Key Technologies

- Hadoop
- Google Cloud Dataproc
- Google Cloud Storage (GCS)
- GCP Cloud Shell
- Linux


### Purpose

The objective of this section is to build practical understanding of Hadoop and distributed data processing by deploying and working with Hadoop in a cloud-based environment.
