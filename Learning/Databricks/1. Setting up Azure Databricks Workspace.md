# Creating an Azure Databricks Workspace

Azure Databricks is a cloud-based data analytics platform built on Apache Spark that enables distributed data processing, data engineering, analytics, and machine learning on Microsoft Azure.

## 1. Create an Azure Databricks Workspace

Search for **Azure Databricks** in the Azure Portal and select **Create** to start configuring a new workspace.

### Project Details
- **Subscription:** Select the Azure subscription to use.
- **Resource Group:** Select an existing resource group or create a new one to organize related Azure resources.

The managed resource group contains infrastructure resources managed by Azure Databricks. It is separate from the resource group used to organize the workspace.

## 2. Configure Networking

Azure Databricks provides networking options to control connectivity between the workspace, compute resources, and other services.

- **Secure Cluster Connectivity (No Public IP):** Adds a more secure networking configuration by removing public IP addresses from cluster nodes.
- **Deploy in Your Own Virtual Network (VNet):** Allows the workspace to use a customer-managed virtual network for networking requirements.

For this learning setup, both options were set to **No**, using the default networking configuration.

## 3. Review and Create

Review the workspace configuration before deployment.

Verify the subscription, resource group, region, pricing tier, workspace type, and networking settings. Select **Create** to deploy the Azure Databricks workspace.

## 4. Launch the Workspace

After deployment completes, open the Azure Databricks resource from the Azure Portal.

Verify that the workspace status is **Active**, then select **Launch Workspace** to open the Databricks environment.

The workspace provides access to notebooks, compute resources, data processing tools, and other Databricks features.

- Understand subscriptions and resource groups in Azure.
- Explore workspace pricing tiers and workspace types.
- Understand basic networking and secure cluster connectivity options.
- Deploy and access an Azure Databricks workspace through the Azure Portal.
