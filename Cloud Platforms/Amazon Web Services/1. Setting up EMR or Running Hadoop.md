## Amazon Web Services (AWS) – Running Hadoop on EC2

Amazon Web Services (AWS) provides managed big data services such as Amazon EMR to run Hadoop and Spark workloads. However, if EMR is unavailable due to account or free-tier restrictions, Hadoop can also be installed manually on an Amazon EC2 instance.

EC2 (Elastic Compute Cloud) provides virtual machines on which you can install a Linux operating system, Java, and Hadoop, and access the Hadoop environment using SSH.

### 1. Amazon EMR vs Amazon EC2

**Amazon EMR (Elastic MapReduce)**

- Managed service for running big data frameworks such as Hadoop, Spark, and Hive.
- AWS handles much of the cluster provisioning, configuration, and management.
- Suitable for distributed data processing without manually installing the entire Hadoop stack.

**Amazon EC2 (Elastic Compute Cloud)**

- Provides virtual machines (instances) in the AWS cloud.
- You can install Linux, Java, and Hadoop manually.
- Requires you to configure and manage the environment yourself.
- Useful for learning Hadoop when EMR is unavailable due to account restrictions.
