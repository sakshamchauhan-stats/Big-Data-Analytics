# Azure Blob Storage / Data Lake Setup

This document covers the creation and configuration of an Azure Storage Account and a storage container for storing data used during the Big Data Engineering learning exercises.

### Objective

The objective was to create a cloud storage resource on Microsoft Azure to store sample datasets that could later be accessed and processed using services such as Azure Virtual Machines, Azure Databricks, Azure Data Factory, and Azure Synapse Analytics.

### Environment

- Cloud Platform: Microsoft Azure
- Storage Service: Azure Blob Storage
- Storage Account Type: General-purpose v2 (StorageV2)
- Storage Account Name: storagefordeprojects1
- Container Name: container-for-adhoc-data-files
- Hierarchical Namespace (ADLS Gen2): Enabled
- Redundancy: LRS
- Default Encryption: Microsoft-managed keys (platform-managed encryption at rest)

These configurations provide a foundation for storing datasets securely while learning cloud-based data engineering. If Hierarchical Namespace is enabled, the storage account also supports Azure Data Lake Storage Gen2 capabilities, including directory-based organization and access control lists (ACLs).
